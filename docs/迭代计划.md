# 生成式软件工程课程设计平台 —— 迭代版本划分与 MVP 范围

> 对应需求版本：V1.2（见 `docs/需求分析列表.md`）

## 一、划分原则

1. 每个迭代都交付**可运行、可验收**的版本，不做半截功能
2. MVP 必须跑通一条完整教学闭环，能真实开一门课、走完一个步骤
3. 两项核心可变设计**数据结构前置、功能后置**：交付物类型字典（F3.3/F8.2）、大模型服务配置（F8.5）在迭代 0 就建表预留，后续迭代只加功能不改表
4. AI 能力整体后置，但后端大模型服务接口抽象在迭代 0 定义好，AI 未启用时不影响主流程

## 二、迭代总览

| 迭代 | 版本 | 主题 | 一句话目标 | 相对工作量 |
|------|------|------|------------|------------|
| 0 | v0.1 | 工程基座 | 前后端骨架、数据库、统一规范就位 | 小 |
| **1** | **v0.2（MVP）** | **教学闭环** | **一个班级一门课，走完「建步骤→提交→批改→总评」** | **中** |
| 2 | v0.3 | 效率与体验 | 模板复用、批量操作、通知提醒、成绩导出 | 中 |
| 3 | v0.4 | AI 辅助 | 打通 DeepSeek 配置与类型感知评阅 | 中 |
| 4 | v1.0 | 运营与正式发布 | 日志、看板、AI 助教、安全与性能加固 | 中 |

## 迭代 0：工程基座（v0.1）

**内容**

- 后端：Spring Boot 4（JDK 21+）项目骨架、MySQL 8 建库、Flyway/Liquibase 迁移脚本
- 后端基座：统一响应体、全局异常、参数校验、JWT 过滤器、RBAC 权限注解、OpenAPI 文档、CORS
- 前端：Vue 3 + Vite + TypeScript + Pinia + Router + Element Plus、axios 封装、动态路由与按钮级权限
- 基础设施：文件存储抽象接口（MVP 用本地磁盘，可切 MinIO/OSS）、逻辑删除基类、审计字段
- **前置建表**：`dict_deliverable_type`、`ai_service_config`、`step_deliverable_item`、`submission_item` 等核心表结构一次建好
- 大模型服务接口抽象（`AiService` / `AiClient` 接口 + `NoopAiClient` 空实现）

**验收**：前后端能启动、迁移脚本可重复执行、登录接口与权限拦截器可用、健康检查通过。

## 迭代 1：MVP（v0.2）—— 重点

### 目标

管理员创建教师账号 → 教师建班并发邀请码 → 学生进班 → 教师建课程/步骤并配置交付项 → 学生逐项提交 → 教师批改评分 → 按权重汇总总评 → 学生查看反馈。

### 纳入范围

| 模块 | 纳入 | 简化说明 |
|------|------|----------|
| F1 用户认证 | F1.1~F1.5 全部 | 管理员账号内置；教师由管理员创建；学生自助注册 + 邀请码进班；取消「激活码审核」 |
| F2 班级课程 | F2.1、F2.2、F2.5 | 教师直接建课程；课程模板（F2.3/F2.4）后置 |
| F3 步骤 | F3.1、F3.2、**F3.3**、F3.5、F3.6 | 交付项配置为核心必做；模板复用（F3.4）、步骤依赖（F3.7）后置 |
| F4 提交进度 | F4.1~F4.5、F4.7、F4.8 | 进度总览简化为「按步骤的完成情况列表」，可视化仪表盘后置 |
| F5 评分 | F5.1、F5.3、F5.5 | 单一分数 + 评语；多维度评分（F5.2）、Excel 导出（F5.4）后置 |
| F8 系统管理 | F8.1、F8.2（部分） | 仅附件大小上限、交付物类型字典维护；AI 总开关先建好但恒为关闭 |

### MVP 支持的交付物类型（4 种）

`文档`（pdf/docx/md）、`代码压缩包`（zip）、`源码仓库`（URL）、`文本说明`（多行文本）

> 足以验证「按类型动态渲染控件 + 类型专属校验 + 类型字典可扩展」这一核心机制；图片、演示地址、其他附件在迭代 2 补齐。

### MVP 明确不做

- 一切 AI 功能（F6 全部）
- 站内消息、截止提醒、定时任务（F7 全部）
- 课程/交付物模板复用、步骤间依赖、允许补交、成绩申诉
- 评分维度配置、成绩导出、进度仪表盘、统计看板、操作日志
- 多套大模型配置、连通性测试界面
- 移动端深度适配（仅保证 PC 端完整可用，布局响应式）

### MVP 验收标准（DoD）

1. 三种角色分别登录后只能看到本角色菜单，越权访问接口返回 403
2. 教师生成邀请码，学生凭码进班；失效/超额/重复的邀请码被拒绝
3. 教师创建含 3 个不同交付项（文档 + zip + GitHub URL）的步骤
4. 学生提交页自动渲染出对应 3 类控件；漏填必填项或 URL 格式错误时无法提交
5. 学生重复提交产生新版本，历史版本可查且不覆盖
6. 教师批改页按交付项分区展示，文件可下载、URL 可跳转，给出分数与评语
7. 两个步骤设置不同权重后，系统自动算出学生课程总评且结果正确
8. 学生端可见自己的进度时间线与成绩评语
9. 新增一种交付物类型只需字典表加记录 + 前端注册组件，无需修改提交主流程代码

## 迭代 2：教学效率与体验（v0.3）

- F2.3 / F2.4 课程模板：管理员维护模板，教师一键套用
- F3.4 常用交付物模板、F3.7 步骤间依赖
- F4.3 允许补交、F4.6 全班进度仪表盘（完成率、缺失交付项、逾期名单）
- F4 补齐剩余交付物类型：截图/图片、在线演示地址、其他附件
- F5.2 评分维度配置、F5.4 成绩 Excel 导出、F5.5 留言/申诉
- F7.1~F7.3 站内消息、截止提醒定时任务、已读管理
- 批量批改、批量下载学生成果

**验收**：教师可在 10 分钟内用模板搭好一门含 5 个步骤的课；到期未交学生自动收到提醒；成绩可一键导出。

## 迭代 3：大模型辅助（v0.4）

**顺序要求：先配置，后能力**

1. F8.5 大模型服务配置（多套配置、DeepSeek 默认、连通性测试、设为当前启用、启停）
2. F8.6 配置安全（AES 加密、脱敏、管理员专属、变更日志、日志过滤密钥）
3. F6.6 服务接口落地实现（DeepSeek 适配器，保持可替换）
4. F6.1 类型感知 AI 辅助评阅（文档 / zip / 仓库 URL 分别处理，建议仅供教师参考，不自动计分）
5. F6.2 成果要点摘要、F6.3 辅助生成步骤要求与评分标准
6. F6.5 Token 用量统计、失败重试与降级

**验收**：关闭 AI 总开关时全流程与 v0.3 完全一致；配置错误或 API 超时不影响提交与评分；密钥在数据库、接口、日志中均不以明文出现。

## 迭代 4：运营与正式发布（v1.0）

- F8.3 操作日志与登录日志、F8.4 数据统计看板
- F6.4 学生侧 AI 助教（限定步骤上下文，含内容安全与额度控制）
- 安全加固：文件类型白名单、防篡改、限流、越权用例回归
- 性能：500+ 并发场景压测、大文件上传异步化、慢 SQL 优化
- 运维：数据库定时备份、部署脚本、部署与使用说明

## 三、风险与依赖

| 风险 | 应对 |
|------|------|
| Spring Boot 4 需 JDK 21+，部分依赖兼容性待验证 | 迭代 0 先做技术验证，锁定版本后再开发业务 |
| 交付物类型字典是全局配置，已有数据后改 `code` 会破坏提交项 | 迭代 0 定稿编码规范，字典只允许新增/停用，不允许修改 |
| `constraint_json`、`params_json` 依赖 MySQL 8 JSON 字段 | 迁移脚本明确使用 JSON 类型并做好默认值 |
| DeepSeek API 需真实密钥与外网连通 | AI 迭代独立可关停；无密钥时 v0.1~v0.3 均可正常开发演示 |
| 文件上传成为安全与性能瓶颈 | 迭代 0 就定义大小上限与类型白名单；大文件异步化放迭代 4 |
